# WTDKP4C5-S1 完整接线图（根据代码生成）

## ═══════════════════════════════════════════════════════
## C5 ↔ P4 UART 交叉连线 (仅需 2 根杜邦线)
## ═══════════════════════════════════════════════════════

C5 J2-16 (GPIO24) ────────→ P4 J2-30 (GPIO11)
C5 J2-14 (GPIO25) ←──────── P4 J2-37 (GPIO10)
38400 8N1

## ═══════════════════════════════════════════════════════
## P4 I2S 总线并联 (3 根杜邦线，P4 偷听麦克风)
## ═══════════════════════════════════════════════════════

C5 GPIO4  (BCLK) ────────→ P4 GPIO0  (J2-25, I2S Slave BCLK)
C5 GPIO5  (WS)   ────────→ P4 GPIO51 (J3-12, I2S Slave WS)
INMP441 SD ───────┬──────→ C5 GPIO6  (I2S Master RX)
                  └──────→ P4 GPIO52 (J3-10, I2S Slave SD)

P4 为 I2S Slave（只听不发），C5 保持 I2S Master 不变。
P4 收到 PCM 后跑唤醒词检测 "小智"，命中后通过 UART 通知 C5 开始录音。

## ═══════════════════════════════════════════════════════
## 跨板连接汇总 (5 根杜邦线)
## ═══════════════════════════════════════════════════════

| 线号 | 信号     | C5 端          | P4 端         | 方向     |
|------|----------|----------------|---------------|----------|
| ①    | UART TX  | J2-16 (GPIO24) | J2-30 (GPIO11)| C5→P4    |
| ②    | UART RX  | J2-14 (GPIO25) | J2-37 (GPIO10)| P4→C5    |
| ③    | I2S BCLK | J2-15 (GPIO4)  | J2-25 (GPIO0) | C5→P4    |
| ④    | I2S WS   | J2-17 (GPIO5)  | GPIO51 (J3-12)| C5→P4    |
| ⑤    | I2S SD   | —              | GPIO52 (J3-10)| 并到INMP441|

> **线 ③④⑤ 为本次新增**。P4 通过这 3 根线"偷听" INMP441 麦克风，跑唤醒词检测。
> P4 是 I2S Slave（只听不发），C5 是 I2S Master（出 BCLK/WS 时钟）。
> 线 ⑤：INMP441 的 SD 脚同时连 C5 GPIO6 和 P4 GPIO52 (J3-10)（一根线并联两个输入脚）。

## C5 侧 — AI 语音
## ═══════════════════════════════════════════════════════

### ── I2S 全双工 (共享 BCLK/WS) ─────────────────────────
| 信号 | GPIO | 连接器脚 | 连到                  |
|------|------|----------|-----------------------|
| BCLK | 4    | J2-15    | INMP441 SCK + MAX98357A BCLK |
| WS   | 5    | J2-17    | INMP441 WS  + MAX98357A LRCK |
| DIN  | 6    | J2-19    | INMP441 SD (麦克风数据)      |
| DOUT | 23   | J2-18    | MAX98357A DIN (扬声器数据)   |

```
完整 I2S 总线拓扑 (16kHz 16-bit mono, BCLK=512kHz)

                    C5 (I2S Master, I2S_NUM_0)
                    ┌─────────────────────────────┐
                    │ GPIO4  BCLK ──┬── INMP441 SCK       │
                    │               ├── MAX98357A BCLK    │
                    │               └── P4 GPIO0 (J2-25)  │ ← ③ NEW
                    │                                     │
                    │ GPIO5  WS   ──┬── INMP441 WS        │
                    │               ├── MAX98357A LRCK    │
                    │               └── P4 GPIO51 (J3-12)  │ ← ④ NEW
                    │                                     │
                    │ GPIO6  DIN  ←── INMP441 SD          │
                    │               └── P4 GPIO52 (J3-10)  │ ← ⑤ NEW (并联)
                    │                                     │
                    │ GPIO23 DOUT ──→ MAX98357A DIN       │
                    └─────────────────────────────┘

                    P4 (I2S Slave, I2S_NUM_1)
                    ┌─────────────────────────────┐
                    │ GPIO0  BCLK_IN ← C5 GPIO4   │
                    │ GPIO51 WS_IN   ← C5 GPIO5   │
                    │ GPIO52 SD_IN   ← INMP441 SD │
                    │                             │
                    │ 跑唤醒词 "小智" + 本地命令   │
                    │ 命中后 UART → C5            │
                    └─────────────────────────────┘
 
 注意:
 - INMP441 L/R 接 GND (左声道)
 - INMP441 VDD 接 3.3V
 - MAX98357A VDD 接 3.3~5V
 - BCLK/WS 走线串 33Ω 防反射
 - SD (GPIO6↔GPIO52) 并联，高阻输入，不需要缓冲器
 - C5 和 P4 必须共地 (GND 已通过 J2 连通)
```
