# WTDKP4C5-S1 化工厂巡逻机器人 PCB 制版接线配置表
**版本**：2026-06-11 代码确认最终版  
**适用**：立创EDA/Altium Designer PCB绘制、排针排母插接式焊接、整机调试  
**核心原则**：所有模块均采用2.54mm间距排针排母插接设计，便于拆卸维修和模块替换  
**代码对照**：本表所有 GPIO 编号已与 `components/hardware/motor_control.h`、`encoder.h`、`display_lcd.h`、`c5_bridge.h`、`cam_ov5647.h`、`mpu6050.h`、`mq135.c`、`mq136.c`、`button.h`、`cam_ov5647.c` 逐项核对一致

4. 禁止用板载5V/3.3V给电机供电
