## PCB 走线规则

| 参数 | 值 | 适用范围 |
|------|-----|---------|
| 最小线宽 | 6mil (0.15mm) | 信号线 |
| 12V走线 | 80mil (2mm) | 电机电源 |
| 5V走线 | 40mil (1mm) | 传感器供电 |
| 3.3V走线 | 20mil (0.5mm) | 逻辑供电 |
| 线间距 | ≥6mil | 常规信号 |
| 大电流间距 | ≥5mm | 电机线与信号线之间 |
| 过孔内径/外径 | 0.3mm/0.6mm | 信号换层 |
| 过孔内径/外径 | 0.6mm/1.0mm | 电源换层 |
| 铺铜网格 | Solid | GND平面 |

## 关键走线注意事项

### 1. I2C 总线 (100kHz)
- 保持走线长度 < 20cm
- SDA/SCL 尽量等长并行
- 上拉电阻靠近 P4 端放置
- **必须**接 4.7kΩ 上拉至 3.3V

### 2. 电机 PWM (10kHz)
- 远离 I2C 和 I2S 走线
- 靠近 TB6612 引脚放置
- 可串联 33Ω 限流电阻

### 3. 编码器信号
- 双绞线或并行走线 (A/B相一起走)
- 可加 10kΩ 上拉至 3.3V 改善波形
- 远离电机大电流线

### 4. I2S 音频
- BCLK/WS/DIN 走线尽量等长
- 音频地与电源地单点连接
- MAX98357A 靠近扬声器接口

### 5. MQ 传感器分压
- 分压电阻 (10kΩ + 20kΩ) 紧靠 P4 GPIO
- 走线避开 PWM 区域

### 6. 12V 电源
- 星形拓扑，先到 TB6612 VM，再到 DC-DC
- DC-DC 输入加 LC 滤波
- 电机大电流回路面积最小化

## 铺铜建议

```
Layer 1 (TOP):  信号 + GND 铺铜
Layer 2 (INNER1): GND 完整平面 (四层板)
Layer 3 (INNER2): 3.3V + 5V 电源分割 (四层板)
Layer 4 (BOTTOM): 信号 + GND 铺铜 (大电流走线)
```

## 冲突修复焊接确认清单

- [ ] VL53L1X XSHUT → GPIO25 (J3-35)，避开摄像头XCLK (GPIO24)
- [ ] M4电机 PWM → GPIO20 (J2-32)，**不是** GPIO50
- [ ] M4电机 IN1 → GPIO28 (J3-29)，**不是** GPIO49
- [ ] M4电机 IN2 → GPIO29 (J3-27)，**不是** GPIO50
- [ ] MQ135 AO → 10kΩ → GPIO49 (J3-16) → 20kΩ → GND
- [ ] MQ136 AO → 10kΩ → GPIO50 (J3-14) → 20kΩ → GND
- [ ] I2C0 (GPIO42/41) → 4.7kΩ → 3.3V
- [ ] I2C1 (GPIO54/53) → 4.7kΩ → 3.3V
- [ ] EN/BOOT/U0TXD/U0RXD 无走线
